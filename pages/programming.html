🌐 JavaScript — Fundamentos

JavaScript es el lenguaje del navegador. Se usa para hacer páginas web interactivas y para desarrollo de servidores con Node.js.

// Variables
const nombre = "Carlos";
let edad = 22;

// Función flecha
const saludar = (nombre) => `Hola, ${nombre}!`;
console.log(saludar(nombre));

// Arreglos y métodos
const notas = [8, 9, 7, 10];
const promedio = notas.reduce((a, b) => a + b, 0) / notas.length;
console.log("Promedio:", promedio);
  • var, let y const
  • Funciones, arrow functions y closures
  • DOM y eventos del navegador
  • Promesas y async/await
  • Fetch API y JSON

🗂️ Estructuras de datos

  • Arreglo (Array): colección ordenada de elementos de acceso por índice.
  • Lista enlazada: nodos conectados mediante punteros.
  • Pila (Stack): último en entrar, primero en salir (LIFO).
  • Cola (Queue): primero en entrar, primero en salir (FIFO).
  • Árbol binario: estructura jerárquica con un nodo raíz y subárboles.
  • Tabla hash: búsqueda en O(1) promedio usando una función hash.
  • Grafo: conjunto de vértices y aristas, dirigido o no dirigido.

⚙️ Algoritmos fundamentales

  • Búsqueda lineal: O(n) — recorre elemento a elemento.
  • Búsqueda binaria: O(log n) — requiere lista ordenada.
  • Ordenamiento burbuja: O(n²) — compara pares adyacentes.
  • Ordenamiento rápido (QuickSort): O(n log n) promedio.
  • BFS/DFS: recorrido de grafos en anchura o profundidad.
  • Programación dinámica: memoización para evitar cálculos repetidos.
