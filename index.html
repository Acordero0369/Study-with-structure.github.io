🔗 Contenido externo

Este sitio puede incorporar automáticamente contenido de otro repositorio mediante GitHub Actions. Para activarlo, edita el archivo .github/workflows/deploy.yml y reemplaza el valor de EXTERNAL_REPO con la URL del repositorio que deseas usar.

El flujo de trabajo clonará ese repositorio durante el despliegue y copiará su contenido a la carpeta external/ de este sitio.
